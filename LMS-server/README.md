# Futura LMS Backend API

The **Futura LMS Backend** is a RESTful API built using **Node.js**, **Express.js**, and **MongoDB** to power the Learning Management System (LMS) used at **Futura Labs Kochi**.  
It manages students, trainers, courses, modules, attendance, assignments, and project evaluations — providing a complete backend solution for institutional learning management.

---

##  Tech Stack

- **Runtime:** Node.js (v18+)
- **Framework:** Express.js
- **Database:** MongoDB with Mongoose ODM
- **Authentication:** JSON Web Token (JWT)
- **File Handling:** Multer (for image uploads)
- **Hosting:** Render.com
- **Environment Management:** dotenv

---

##  Features

- 👥 **User Management** – Handles admin, trainer, and student accounts  
- 📚 **Course & Module Management** – Create, update, delete, and fetch course details  
- 🗓️ **Attendance Tracking** – Record and retrieve daily attendance  
- 🧾 **Assignments Module** – Manage student submissions and marks  
- 💬 **Project & Review System** – Add and review student projects  
- 🧩 **Dynamic Database Handling** – Separate databases per institution for scalability  
- 🖼️ **File Upload Support** – Upload profile images or documents using Multer
